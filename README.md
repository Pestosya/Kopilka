# Копилка

Обновлённое приложение для личных финансов на основе исходного прототипа.

## Что внутри

- доходы и расходы с поиском и фильтрами;
- отдельные наличные, банковские карты и накопительные счета;
- переводы между своими счетами без искажения статистики доходов и расходов;
- регулярные зарплаты, подписки и коммунальные платежи с автоматическим созданием операций;
- напоминания заранее внутри приложения и системные уведомления по разрешению пользователя;
- кредиты, микрозаймы и личные долги с количеством платежей и датами;
- расчёт процентов, тела кредита, следующего платежа и остатка графика;
- аннуитетные и дифференцированные кредиты, комиссии, пени и банковское округление;
- досрочное погашение с уменьшением срока или размера платежа;
- календарь будущих платежей с разбивкой по дням и месяцам;
- финансовый пульс и подсказки;
- прогноз баланса, динамика капитала и сравнение месяцев;
- стратегии погашения долгов «снежный ком» и «лавина»;
- цель финансовой подушки;
- светлая и тёмная темы;
- резервные копии и импорт данных из старого прототипа;
- установка на компьютер или телефон как PWA;
- серверная регистрация и вход по логину и паролю;
- синхронизация одного аккаунта между телефоном и компьютером;
- SQLite-база на сервере;
- финансовая база хранится на сервере как зашифрованный AES-256 сейф — суммы не лежат в БД открытым текстом;
- единое меню профиля с фотографией, настройками, темой и выходом;
- блокировка приложения паролем или PIN-кодом и поддержка системной биометрии;
- пароль для расшифровки базы после полного перезапуска; PIN и биометрия — для повторной блокировки в текущем сеансе;
- усиленное хеширование паролей PBKDF2, защита от перебора и автоматическое обновление старых хешей;
- настраиваемая автоблокировка и блокировка после сворачивания приложения;
- зашифрованные резервные копии AES-256 с отдельным паролем;
- одинаковый набор основных функций на компьютере и телефоне.

## Запуск

После перехода на серверные аккаунты приложение нельзя полноценно запускать двойным кликом по `index.html`: нужен backend.

Установите зависимости:

```bash
npm install
```

Запустите сервер:

```bash
npm start
```

После этого откройте `http://localhost:3000`.

По умолчанию база создаётся в `server/data/kopilka.sqlite`. Для сервера лучше указать отдельный постоянный путь:

```bash
DB_PATH=/var/lib/kopilka/kopilka.sqlite PORT=3000 npm start
```

## Переменные окружения

Скопируйте `.env.example` и задайте значения на сервере:

- `PORT` — порт приложения;
- `DB_PATH` — путь к SQLite-базе;
- `SESSION_DAYS` — срок серверной сессии;
- `COOKIE_SECURE=true` — включить защищённые cookie на HTTPS;
- `TRUST_PROXY=1` — включить, если приложение стоит за nginx/прокси.

## Docker

```bash
docker build -t kopilka-finance .
docker run -p 3000:3000 -v kopilka-data:/data --env-file .env.example kopilka-finance
```

## Важно по безопасности

- Ставьте приложение только на HTTPS. Без HTTPS биометрия и защищённые cookie будут работать ограниченно.
- Пароль нужен не только для входа, но и для расшифровки финансовой базы.
- Сервер хранит зашифрованный сейф данных. Если забыть пароль, восстановить содержимое сейфа без резервной копии не получится.
- Резервные копии в настройках остаются полезными: они тоже зашифрованы отдельным паролем.

## Структура и проверка

- `modules/migrations.js` — версии формата данных и безопасное обновление старых сохранений;
- `modules/finance.js` — независимые финансовые расчёты;
- `modules/security.js` — хеширование, шифрование и расшифровка;
- `server/index.js` — серверная авторизация, сессии и API синхронизации;
- `server/storage.js` — подключение и схема SQLite;
- `app.js` — интерфейс и связывание модулей.

Запуск автоматических тестов:

```bash
npm test
```

Полная проверка синтаксиса и тестов:

```bash
npm run check
```
